# REST API 仕様（本番：学会HP・事務局サーバ）

`index.html` の `API_BASE` を設定すると、以下のAPIを使う保存方式に切り替わります。
すべて JSON（`Content-Type: application/json`）で、Cookie による会員ログインのセッションを使います（`credentials: "include"`）。

**認証と権限はサーバ側で必ず制御してください。** 画面側の表示制御は利便性のためのもので、セキュリティの根拠にはなりません。

## 権限

| 役割 | 判定 | 許可する操作 |
| --- | --- | --- |
| 会員 | 会員専用ページにログイン済み | 本人の申告の取得・保存、運用モードの取得 |
| 管理（事務局・TF） | `canViewTF = true` の会員（事務局が付与） | 上記に加え、全申告の取得、運用モードの変更、訓練記録の取得・追加 |

## エンドポイント

| メソッド | パス | 権限 | 内容 | 応答 |
| --- | --- | --- | --- | --- |
| GET | `/me` | 会員 | ログイン中の会員の情報 | `{ "id": "会員ID", "canViewTF": false }` |
| GET | `/reports/me` | 会員 | 本人の申告 | Report。未登録なら `404` |
| PUT | `/reports/me` | 会員 | 本人の申告を保存（全体を置き換え） | `204` |
| GET | `/reports` | 管理 | 全申告 | Report の配列 |
| GET | `/mode` | 会員 | 現在の運用モード | Mode。未設定なら `404` |
| PUT | `/mode` | 管理 | 運用モードを変更 | `204` |
| GET | `/summary` | 会員 | 申請側の地図に使う匿名の集計 | Summary。未作成なら `404` |
| PUT | `/summary` | 管理 | 匿名の集計を更新（管理画面が申告の変更時に自動で送る） | `204` |
| GET | `/board` | 会員 | 掲示板の書き込み | Post の配列 |
| POST | `/board` | 会員 | 掲示板に書き込む。区分 `tf`・`society` は管理のみ、`gov` は管理と担当都道府県の連絡員のみ（サーバで検証） | `204` |
| PATCH | `/board/{id}` | 管理（または書き込んだ本人） | 解決済みの切替 `{resolved}`、削除 `{deleted:true}` | `204` |
| GET | `/prefstatus` | 会員 | 都道府県の状況 `{都道府県: PrefStatus}` | object |
| PUT | `/prefstatus/{pref}` | 管理、または当該都道府県の連絡員 | 都道府県の状況を保存 | `204` |
| GET | `/liaisons` | 会員 | 都道府県連絡員 `[{fid, pref, role}]`（氏名は返さない） | 配列 |
| PUT | `/liaisons` | 管理 | 都道府県連絡員の指定 | `204` |
| GET | `/drills` | 管理 | 訓練記録の一覧 | Drill の配列 |
| POST | `/drills` | 管理 | 訓練記録を追加 | `204` |

- 画面は `/reports`・`/mode`・`/drills`・`/summary` を約30秒ごとに再取得します。
- `/summary` は件数の集計と、会員向けの表示に使う施設一覧（施設名・種別・所在地・所属薬剤師会・対応機能・最終更新）です。氏名・会員番号・電話・メール・補足は含めません。施設名と所在地（住所）は、会員向けの表示に同意した申告（consentVer 2 以上）に限ります。位置（緯度・経度）は小数点以下5桁に丸めて含めます。サーバ側で `/reports` から作り直して返す実装でも構いません（その場合、`PUT /summary` は不要）。
- `PUT /reports/me` では、サーバ側で `memberNo` をログイン中の会員番号と照合してください。
- `updatedAt` はクライアントが送る値ですが、訓練の集計に使うため、サーバの受信時刻で上書きすることを推奨します。
- 権限がない場合は `403` を返してください。画面は保存失敗として扱います。

データ項目の詳細は [data-model.md](data-model.md)、機械可読な定義は [openapi.yaml](openapi.yaml) を参照してください。

## 保存期間とログ

- 申告データの保存期間と提供時の手続きは、学会の個人情報保護方針に定めます（BCP第27条）。
- CSV の出力と、外部（災害薬事コーディネーター等）への提供は、事務局がログを残すことを推奨します。
