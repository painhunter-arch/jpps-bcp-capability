# JPPS災害時緩和ケア機能 稼働申告System（試作版）

一般社団法人日本緩和医療薬学会 災害対策緩和医療薬学タスクフォース（災害対策TF）

Copyright © 2026 伊東俊雅（Toshimasa Ito）. All rights reserved.（[COPYRIGHT.md](COPYRIGHT.md)）

会員の所属施設が提供できる緩和ケア機能を「対応可／要相談／不可」の3段階で申告し、災害時に事務局とTFが被災地域の状況を集計するためのシステムです。
「災害対策TF 事業継続計画（BCP）（案）」第8章と資料2に対応します。

> 本リポジトリは、理事会審議用の **試作版** です。本番は学会HPの会員専用ページ配下にHTMLで実装し、申告データは事務局が管理します（BCP第24条）。

## 申告項目

| 項目 | 内容 | 値 |
| --- | --- | --- |
| 医療用麻薬（内服・貼付） | 自施設の患者への調剤・施用、災害時の譲渡特例による他施設への譲渡 | 対応可／要相談／不可 |
| 医療用麻薬注射剤・PCA | 注射剤の調製、PCAポンプの運用・貸出し | 同上 |
| 在宅訪問（緩和ケア） | 在宅患者への訪問薬剤管理、薬剤の届け | 同上 |

申告者情報として、氏名・会員番号・災害時に通じる電話番号・メールアドレス・所属薬剤師会（都道府県／地域（地区）／都道府県病院薬剤師会。任意）を記載します。
**医療用麻薬の在庫数量は収集しません**（盗難リスクの回避）。

## 主な機能

- 申告画面（会員）：申告の登録・更新、各項目の法的根拠の表示
- 集計画面（事務局・TF）：都道府県別集計、市区町村別集計、申告一覧、所属薬剤師会・適用市町村での絞り込み、CSV出力
- 所在地：申告時に住所を入力させ、都道府県・市区町村を自動で読み取り、位置（緯度・経度）を国土地理院の住所検索API（キー不要。Google マップのキーがあれば Google）で求めて保存する
- 地域の稼働状況（画面上部に固定配置。管理画面・申請側で共通）：実地図に似たタイル形式で、全国 → 都道府県（「地区＝地区薬剤師会」と「市域＝市区町村」を切り替え）→ 地区または市域 → 施設 → 施設の詳細の順にたどる。都道府県より下は、保存した位置に基づいて実際の配置に近いタイル配置で描く。どの単位でも同じ形式で、登録施設数と対応可能な業務（麻薬・注射・PCA・在宅）を表示。現在の表示単位をディレクトリ形式（例：`/ 全国 / 熊本県 / 熊本市薬剤師会`）で示し、戻るボタンと、都道府県・薬剤師会・施設名の選択欄を備える。申請側では施設名・種別・所在地・所属薬剤師会・対応機能・最終更新を表示し、氏名・会員番号・電話・メール・補足は表示しない（会員向けの表示に同意した申告のみ施設名を表示）
- 表題・ロゴ：「JPPS災害時緩和ケア機能 稼働申告System」。日本緩和医療薬学会のロゴを、同学会の使用許可を得て表題の上に表示する（画像は index.html に埋め込み済み。原画像は `assets/jpps-logo.jpg`。管理画面で別のURLを指定することも可）。ロゴの権利は同学会に帰属する
- 画面の切り替え：画面上部のタブ（地域の稼働状況・掲示板・申告する・都道府県の状況入力・集計）で切り替え、1画面ずつ表示する（長いスクロールをなくす）。タブは画面上部に固定し、掲示板のタブには未読の件数を表示
- 掲示板（状況共有）：ブログのように日付の見出しつきの時系列（新しい書き込みが上）で、区分は色分けして混在表示し、件数つきのタグで絞り込む。情報提供・不足・支援・TF指示・行政情報・学会指示・その他の7区分。会員は情報提供・不足・支援・その他、都道府県連絡員は行政情報も、学会・TFは全区分に書き込める。区分・都道府県・未解決で絞り込み、解決済みの切替ができる
- 都道府県の状況（都道府県連絡員が入力）：管理画面で会員番号により連絡員を指定。連絡員は担当都道府県の全体の状況（平常・一部に支障・重大な支障・不明）と6項目（医療機関・薬局・医薬品流通・ライフライン・交通・薬剤師会の稼働）、補足を入力。地図の色分けで「都道府県の状況」を選ぶと全国の状況がわかり、都道府県の画面に詳細を表示
- システムバナー（画面上部に固定）：申請施設でログインしている場合と管理画面で、システム名・施設名（管理画面では「管理画面」）・Ver・日付・時刻（秒単位で更新）を表示。申告を保存すると自施設の状況表示ページ（施設の詳細）に移る
- Google マップ（任意。管理画面のみ。APIキー設定時）：施設ごとのピン（既定）、都道府県単位・市区町村単位の円
- 運用モード（管理側のみ操作）：平時／訓練／災害対策。想定・被災地域を都道府県と市町村（災害救助法の適用市町村）の単位で記録
- 訓練モード：回答率（全体・24時間以内・72時間以内）と回答までの時間（中央値）を自動集計し、訓練記録を保存・CSV出力

## 動作モード（保存先は自動で切り替わります）

| 開き方 | 保存先 | 用途 |
| --- | --- | --- |
| `index.html` を単体で開く | 端末のブラウザ内（localStorage） | 操作確認・デモ。会員は申告ファイル（JSON）を書き出してTFへ送付し、TFが読み込んで集計 |
| Git で公開（GitHub Pages 等）し、管理画面で保存先を「Google ドライブ」に設定 | 会員本人の Google ドライブ（申告）と管理用 Google アカウントのドライブ（運用モード・承認・訓練記録） | Git公開版。会員は Google アカウントで連携し、管理者がメールで届く申請を承認。設定手順は [docs/google-drive.md](docs/google-drive.md) |
| `API_BASE` を設定して学会HPに設置 | 事務局のサーバ（REST API） | 本番運用。API仕様は [docs/api.md](docs/api.md) と [docs/openapi.yaml](docs/openapi.yaml) |
| claude.ai のWeb版として公開 | claude.ai の共有データベース | 理事・委員による試用 |

## 管理画面

申告者用と管理用は1つのプログラム（`index.html`）です。画面上部の「管理者（学会・TF）」タブを開き、ID とパスワードを入れると、同じ画面のまま管理機能（集計、運用モード、都道府県連絡員の指定、保存先の設定、連携申請の承認など）が使えるようになります（スタンドアロン版・Git公開版）。ログイン後も、申告・地図・掲示板のタブはそのまま使えます。「管理者からログアウト」で管理機能を閉じます。旧来の `index.html#tf` で開いた場合は、管理者タブが開きます。

| 項目 | 値 |
| --- | --- |
| ID | `AdminJPPS` |
| パスワード | 学会・TF の管理者に別途通知（ソースには SHA-256 のハッシュ値のみを記載） |

> **注意**：ブラウザ内で行う ID・パスワードの照合は、ソースを改変すれば回避できます。データそのものの保護は、Git公開版では Google アカウントの権限（申告ファイルは会員本人と管理用アカウントのみが閲覧可能）、本番では学会サーバの認証によって行います。パスワードを変更する場合は、`index.html` の `ADMIN_HASH` を `SHA-256("AdminJPPS:新しいパスワード")` の値に置き換えます。

本番（学会HP）では、事務局・TF の権限で会員専用ページにログインしたときに管理画面を表示します（サーバ側の認証）。

## すぐに試す

1. `index.html` をブラウザで開き、申告を入力して保存します。
2. 「管理者」タブでログインし、「申告ファイルの読み込み」で `samples/sample-reports.json` を読み込みます（架空のデータです）。
3. 「運用モード（管理）」で「訓練」を選んで開始し、訓練の進捗と訓練記録を確認します。

## 学会HPへの設置手順（概要）

1. `index.html` 冒頭の設定値を変更します。
   - `API_BASE`：事務局サーバのAPIのパス（例：`/api/jpps-bcp`）
   - `GOOGLE_MAPS_API_KEY`：Google Maps Platform のAPIキー（任意）
2. サーバ側で [docs/api.md](docs/api.md) のAPIを実装します。**会員認証とTF・事務局の権限制御はサーバ側で行います。**
3. 会員専用ページの配下に `index.html` を置きます。`API_BASE` を設定すると、申告ファイルの書き出し・読み込みなどスタンドアロン用の表示は自動で非表示になります。

## Google マップの設定（任意）

- 有効にするAPI：Maps JavaScript API、Geocoding API（市区町村単位で表示する場合）
- キーには HTTP リファラ制限をかけ、学会HP以外では使えないようにします。
- Google へ送信するのは「都道府県＋市区町村」の文字列のみで、施設名・氏名・連絡先は送信しません。
- 利用料金の有無と契約名義は、事務局と協議して決めます。

## 個人情報の取扱い

申告データの管理者は事務局です。提供範囲は、TF・地区情報連絡員・依頼を受けた場合の都道府県災害薬事コーディネーターに限り、利用目的は災害時の医薬品供給経路の調整に限ります（BCP第27条、定款第53条）。

**Git で公開する場合の注意**：本リポジトリに実際の申告データ（JSON・CSV）をコミットしないでください（`.gitignore` で除外しています）。Git公開版の申告データは Google ドライブに保存され、リポジトリには含まれません。公開リポジトリに置くのは、管理画面で書き出した `config.json`（OAuth クライアントID、APIキー、管理用アカウント、状態ファイルID）だけです。これらは公開されることを前提とした値で、利用元（HTTPリファラ・承認済みのJavaScript生成元）の制限をかけて使います。
